# Asset notes

- `public/images/` contains original generated concept photographs for the fictional Morrow House project. They are not documentary photographs of a built residence. Replace them with photographs you own or are licensed to publish before using this template for client work.
- `public/fonts/` contains locally served Familjen Grotesk and Instrument Serif files. Their SIL Open Font Licenses are included beside the files.
- `public/readme/` contains two small animated GIFs used only by this repository's README.
- The small SVG house mark is part of the template identity and can be changed in `app/icon.svg`.
